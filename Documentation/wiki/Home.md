# Deploying DDM Update Companion

Use this guide to install the app, manage reminder preferences, and verify behavior on enrolled Macs.

The app displays a countdown and popup for a pending DDM-enforced macOS update. Your MDM sets the update target and deadline; macOS handles installation. The app settings profile controls the reminder interface, not the enforcement deadline.

## Deployment steps

1. Review [MDM compatibility](DDM-Integration.md).
2. [Install the app and choose a startup method](Setup.md).
3. [Deploy managed settings](Managed-Configuration.md).
4. Review [Preferences and user controls](Preferences.md).
5. Complete the [pilot checklist](Testing.md) before broad deployment.

See [Troubleshooting](Troubleshooting.md) for missing reminders, locked preferences, and startup issues.
